# Radinkacraft

Beranda Fase 1 untuk toko bucket bunga dan company profile Radinkacraft, dibuat dengan Next.js App Router, TypeScript, dan Tailwind CSS.

## Menjalankan

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`. Perintah pemeriksaan:

```bash
npm run build
npm run lint
npm run typecheck
```

Konten homepage statis disimpan terpusat di `src/data/homepage.ts` agar mudah dipindahkan ke CMS pada fase selanjutnya. Aset hero dan contoh produk berada di `public/images/`.

## Cakupan fase

Fase 1 mencakup design tokens, font, navigasi responsif, hero, bagian produk unggulan, kategori, keunggulan, ulasan, CTA, dan footer. Database, toko dan detail produk fungsional, checkout, autentikasi, serta panel admin dikerjakan pada fase berikutnya.
